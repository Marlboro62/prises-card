Situation

La carte réagit comme dans Home Assistant : appuyez sur une prise (« Allumer ? » ou « Éteindre ? »), puis une seconde fois pour valider ; appui long pour sa fiche ; clic sur une puissance pour son historique. Le congélateur et la box internet sont verrouillés : rien ne permet de les couper. Rien n'est envoyé : tout se passe dans la page.
